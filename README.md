# Study MBBS Abroad

Welcome to the Study MBBS Abroad project! This repository contains the source code for a website designed to provide information about studying MBBS in various countries.

## Project Overview

This project aims to help students find top universities for studying MBBS abroad. The website provides detailed information about different countries, the admission process, resources, and more.

## Technologies Used

- **HTML**: For the structure of the web pages.
- **Tailwind CSS**: For styling and layout.
- **JavaScript**: For interactivity and dynamic content.

## Features

- **Responsive Design**: The website is fully responsive and works on all devices.
- **Interactive Navigation**: Dropdown menus for easy navigation.
- **Dynamic Content**: JavaScript is used to dynamically load content such as benefits, countries, and admission process.
- **Contact Form**: A form for students to submit their details and get in touch.
